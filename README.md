# Детерминированный синтез изображений на основе обратного пакетного дискретного вейвлет-преобразования (АДСИ / IPDWT Synthesis)

## Описание

Алгоритм позволяет генерировать изображения путём иерархического синтеза из бинарной маски размером 8×8 пикселей. На каждом уровне реконструкции используется только один поддиапазон вейвлет-коэффициентов (LL, LH, HL, HH), что даёт полный контроль над пространственной структурой и иерархией деталей.

Данная программа предоставляет графический интерфейс для интерактивного исследования всех возможных путей реконструкции при заданных параметрах (вейвлет-семейство, количество уровней, seed-маска).

## Зависимости

- Python 3.8+
- numpy
- matplotlib
- PyWavelets (`pywt`)
- tkinter (обычно входит в стандартную поставку Python)
