# Детерминированный синтез изображений на основе обратного пакетного дискретного вейвлет-преобразования (АДСИ)

Алгоритм детерминированного синтеза изображений (АДСИ) получает изображение, например карту высот, из небольшого seed-массива (8 × 8 элементов со значениями от 0 до 1) обратным пакетным дискретным вейвлет-преобразованием (ОПДВП). На каждом шаге реконструкции seed-массив проходит один тип коэффициентов: A — аппроксимирующие (LL), H, V, D — детализирующие горизонтальные, вертикальные и диагональные (HL, LH, HH). Последовательность типов по шагам называется путем реконструкции, например AAA или DAA.

Какой параметр синтеза за что отвечает:

- seed-массив задает форму рельефа: очертания на виде сверху, высоту и профиль склонов;
- путь из одних A дает форму; путь с H, V или D дает муарную составляющую (МуС): полосы или бугры с периодом и направлением, которые задает путь;
- вейвлет-базис определяет вид края формы и величину ее сдвига при синтезе;
- длина пути J задает масштаб: элементу seed-массива на карте соответствует клетка 2^J × 2^J пикселей;
- несколько seed-массивов в разных узлах пакетного дерева с весами собираются в одну карту за один запуск ОПДВП.

Сдвиг формы при синтезе рассчитывается по модели заранее, поэтому форма получается там, где задана в seed-массиве.

## Состав

| Папка, файл | Что внутри |
|---|---|
| `ipdwt_synthesis_3_Lvl.py` | программа с графическим интерфейсом для просмотра всех путей реконструкции (seed-массив 0/1, три уровня) |
| `adsi/adsi_place.py` | синтез по пути, модель сдвига, сборка карты из нескольких узлов в одном запуске с учетом сдвига (`compose`) |
| `adsi/core_synthesis_shift_model.py` | модель накопленного сдвига для произвольного пути и базиса |
| `adsi/example.py` | пример: долина, два холма на дне и неровность по всей форме в одном запуске |
| `stand/stand_adsi.html` | программный стенд: справочный набор и подбор параметров по типовым задачам, открывается в браузере |
| `comparison/` | сравнение с шумовыми методами: реализации шумов, скрипты и результаты замеров |

### comparison

| Файл | Что считает | Результат |
|---|---|---|
| `locality_c.py` | доля площади карты 64 × 64, на которой меняется высота при изменении одного входного значения | `locality_c.json` |
| `time_c.py` | время синтеза одного изображения (256, 512, 1024 пикселя, медиана замеров) | `time_c.json` |
| `mem_c.py` | пиковая память для тех же конфигураций (tracemalloc) | `mem_c.json` |

Реализации шумов (числовой шум, шум Перлина, симплексный шум, вейвлет-шум, алгоритм DS, шум Уорли, fBm) — в `time_c.py`, `c_lib.py` и `fig_gallery.py`. Типовые задачи (рисунки задач и вторые seed-массивы) — `c3_tasks.json`, `c3_valley_kirill.json`, параметры маски и перебора seed — `c_work.json`. Время и память зависят от компьютера: в файлах результатов записана среда, на которой проводились замеры.

## Зависимости

Python 3.8+, numpy, scipy, matplotlib, PyWavelets; для программы с интерфейсом — tkinter (входит в стандартную поставку Python).

```bash
pip install numpy scipy matplotlib PyWavelets
```

## Запуск

```bash
python ipdwt_synthesis_3_Lvl.py         # программа с интерфейсом
cd adsi && python example.py            # пример сборки карты -> example.png
cd comparison && python locality_c.py   # локальность -> locality_c.json
cd comparison && python time_c.py       # время (долго: перебор 100 значений seed)
cd comparison && python mem_c.py        # пиковая память
```
